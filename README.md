# 鬼屋魔影 / Alone in the Dark (1992) — 简体中文补丁

**1992 年 DOS 原版《鬼屋魔影》的简体中文汉化补丁。以 xdelta3 差异补丁方式安装，不随包分发任何被修改过的可执行文件。**

> Unofficial Simplified Chinese fan translation for *Alone in the Dark* (1992, DOS).  
> Installed as an xdelta3 differential patch — no pre-modified executables are distributed.

本补丁只包含汉化资源与安装脚本，不包含游戏本体，也不包含汉化后的主程序。  
汉化主程序 `AITD1CHS.EXE` 在你机器上由原版 `INDARK\INDARK.EXE` 现场生成，补丁仅 1.6 KB。

## 汉化内容

- **18 本书**全部汉化
- **190 条消息**全部汉化
- **两段开场剧本**全部汉化
- 排版：字距 2 px、两端对齐，按原版分页重排
- 拉丁文 / 克苏鲁语咒文**保留原文**，或附中文注解
- 制作人员名单保留原文

**翻译底本**：以**英文版**（`ENGLISH.PAK`）的文本为底本，另有**少数段落参考了法语原版**。

## 安装

1. 到 [Releases](../../releases/latest) 下载最新补丁包（`.zip`）。
2. 解压到**任意位置**：游戏根目录、游戏目录下的子文件夹、或完全无关的路径都可以。
3. 双击 `安装中文版.bat`。

脚本会自动寻找游戏目录，顺序如下，先命中先用：

1. 拖到脚本图标上的目录 —— 先看它本身，再逐级向上；
2. 再在该目录里向下查找 —— 所以拖 `SteamLibrary`、`steamapps`、`common` 这类上级目录也行，甚至拖整个盘符；
3. 脚本自身所在目录，逐级向上；
4. Steam 注册表 → 常见默认路径 → 请你手动指定。

判定依据是 `INDARK\INDARK.EXE`、`GAME.GOG`、`INDARK\ENGLISH.PAK` 这些特征文件，  
不会把补丁包自己的 `files\INDARK` 当成游戏目录。确认前会显示**游戏目录 / 定位依据 / 定位方式**三项，  
机器上有多份副本时请核对是不是你要装的那一份。

1. 安装完成后，双击游戏根目录里的 `简体中文.bat` 启动中文版。

**启动方式**

| 版本  | 启动方式                                 |
| --- | ------------------------------------ |
| 中文版 | 游戏根目录 `简体中文.bat`                     |
| 英文版 | 照旧（Steam 开始游戏 / `DOSBOX\launch.bat`） |

两版共用同一批存档（`INDARK\SAVE0~4.ITD`），互不影响。

## 卸载

安装时会把一份 `卸载中文版.bat` 复制到游戏根目录，**直接去游戏目录双击即可**，不必找回原来的补丁包。  
补丁包里那份同样可用，且会保留下来以后再用。

卸载只删除汉化新增的文件（包括游戏根目录里那份卸载脚本与安装记录 `chsuninstall.txt`），  
原版 `INDARK.EXE`、`ENGLISH.PAK` 与存档**均不受影响**。

**安装记录 `chsuninstall.txt`**：安装成功后会写一份，记录游戏的绝对路径，游戏根目录与补丁包目录各一份。  
卸载时优先读它，直接定位，不必遍历硬盘；机器上有多份游戏副本（例如另开一份做汉化测试）时也不会认错地方。  
记录失效（游戏被移走或删除）时会提示，并自动改回常规查找规则；卸载成功后记录一并删除，  
避免下次安装或卸载照着旧路径误认。

## 安装脚本会做什么

给需要审计的人：

1. 定位游戏目录（读安装记录 → 拖入目录 → 向下查找 → 自身向上查找 → Steam 注册表 → 默认路径）
2. 校验原版 `INDARK\INDARK.EXE` 大小与 MD5，不符则中止
3. 调用 `tools\xdelta3decode.exe` 生成 `AITD1CHS.EXE`（**不改动原版 EXE**）
4. 复制 `SCHINESE.PAK`、`ITD_RCHS.PAK`、`FONTCHS.FNT`、启动器与 DOSBox 配置到游戏目录
5. 写入 `chsuninstall.txt`（记录安装路径与时间）
6. **不联网、不写注册表、不修改系统设置、不触碰存档**

## 原版文件校验值

xdelta 补丁对源文件极其敏感，源不符会直接失败。装之前可以先自查：

| 文件                  | 大小            | MD5                                |
| ------------------- | ------------- | ---------------------------------- |
| `INDARK\INDARK.EXE` | 155,088 B     | `dfb8ed7a937e316815108e0c7259b6a5` |
| `GAME.GOG`          | 353,924,256 B | `9a1ec8ab71cd8a0a2106fb84007680ad` |
| `GAME.INST`         | 793 B         | `4a5b14d75ff02c2bc7ae3569d77c6b4a` |

安装结果 `INDARK\AITD1CHS.EXE` 应为 **156,478 B**，MD5 `d149b5c6abbfa813f9e5975fbb479fde`。

只要 `INDARK.EXE` 的大小是 155,088 字节，一般就是这个版本。若不符，请开 Issue 说明你的来源与文件大小。

## 常见问题

**装不上，提示版本不符**  
`INDARK\INDARK.EXE` 与上表不一致。xdelta 补丁对源文件逐字节敏感，无法跨版本使用。  
请确认是 Steam 版，或开 Issue 附上文件大小。

**在 Steam 里「验证游戏文件完整性」之后汉化没了**  
这是 Steam 的正常行为，会把改动过的文件还原。重新运行一次安装程序即可。  
注意「验证」也可能删掉新增文件，汉化资源需一并重装。

**杀毒软件报警**  
`tools\xdelta3decode.exe` 是 xdelta3 3.2.2 的 32 位精简解码器，本身无网络功能，  
偶有杀软对这类小体积命令行程序误报。介意的话可以从  
[xdelta 官方仓库](https://github.com/jmacd/xdelta)自行编译同版本解码器替换。

**能不能装到 GOG 版 / 光盘版 / 其他语言版**  
未验证。请先备份，再对照上面的校验值确认 `INDARK.EXE` 是否一致。  
不一致就不要装 —— 补丁会在校验阶段中止，不会留下半成品文件。

**中文版和英文版会互相影响吗**  
不会。中文版使用独立的 `AITD1CHS.EXE` 与独立 DOSBox 配置，原版文件保持不动，  
存档是共用的。卸载后完全回到英文版原状。

**译文和英文版语音对不上**  
翻译以英文版为底本，但少数段落参考了法语原版。  
所以个别措辞、语气不是逐字对应，这是有意的处理，不是错译。
若你发现疑似真正的错译或漏译，欢迎开 Issue，注明书籍页或消息编号。
