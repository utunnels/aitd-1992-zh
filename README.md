# 鬼屋魔影 / Alone in the Dark (1992) — 简体中文补丁

**1992 年 DOS 原版《鬼屋魔影》的简体中文汉化补丁。以 xdelta3 差异补丁方式安装，不随包分发任何被修改过的可执行文件。**

> Unofficial Simplified Chinese fan translation for *Alone in the Dark* (1992, DOS).  
> Installed as an xdelta3 differential patch — no pre-modified executables are distributed.

本补丁只包含汉化资源与安装脚本，不包含游戏本体，也不包含汉化后的主程序。  
汉化主程序 `AITD1CHS.EXE` 在你机器上由原版 `INDARK\INDARK.EXE` 现场生成，补丁仅 1.6~1.7 KB。

## 汉化内容

- **18 本书**全部汉化
- **190 条消息**全部汉化
- **两段开场剧本**全部汉化
- 排版：字距 2 px、两端对齐，按原版分页重排
- 拉丁文 / 克苏鲁语咒文**保留原文**，或附中文注解
- 制作人员名单保留原文

**翻译底本**：以**英文版**（`ENGLISH.PAK`）的文本为底本，另有**少数段落参考了法语原版**。

## 投掷修复（可选，默认安装）

修原版两个毛病：**投掷物品容易卡住**（背靠墙时东西直接掉在脚下、扔不出去），  
以及**投掷音效的播放问题**（挥手音偏晚、落地那声被盖住）。

安装程序会问一句：**直接回车 = 安装**（推荐），**输入 `N` = 只装汉化**；  
也可以用 `CHS_THROWFIX=1` / `CHS_THROWFIX=0` 免交互指定。

**不改动任何原版文件**：修复用的数据另存成 `LIST_FIX.PAK` 与 `PRIO_FIX.ITD`，  
中文版主程序读这两个文件就行；英文版照旧读原来的 `LISTLIFE.PAK` / `PRIORITY.ITD`。  
卸载时把它们删掉即可，所以不存在「装过汉化之后英文版被改坏」这种情况。

## 安装

1. 到 [Releases](../../releases/latest) 下载最新补丁包：  
   `aitd-1992-zh_v2.1.0.zip`（约 208 KB，文字补丁，必装）／  
   `aitd-1992-zh-voicepack_v2.1.0.zip`（20.4 MB，配音包，可选）。
2. 解压到**任意位置**：游戏根目录、游戏目录下的子文件夹、或完全无关的路径都可以。
3. 双击 `安装中文版.bat`。
4. 脚本会问是否同时安装投掷修复（回车 = 装，`N` = 跳过，见上一节；不影响原版文件）。
5. 安装完成后，双击游戏根目录里的 `简体中文.bat` 启动中文版。

**找游戏目录的顺序**（先命中先用）：

1. 拖到脚本图标上的目录 —— 先看它本身，再逐级向上；
2. 再在该目录里向下查找 —— 所以拖 `SteamLibrary`、`steamapps`、`common` 这类上级目录也行，甚至拖整个盘符；
3. 脚本自身所在目录，逐级向上；
4. Steam 注册表 → 常见默认路径 → 请你手动指定。

判定依据是 `INDARK\INDARK.EXE`、`GAME.GOG`、`INDARK\ENGLISH.PAK` 这些特征文件，  
不会把补丁包自己的 `files\INDARK` 当成游戏目录。确认前会显示**游戏目录 / 定位依据 / 定位方式**三项，  
机器上有多份副本时请核对是不是你要装的那一份。

> **不要求标准 Steam 目录结构**：脚本只认 `INDARK.EXE` 的校验值。  
> 如果你是把文件夹**拖到脚本上**或**手输路径**指定的目录，脚本还会检查 `DOSBOX\DOSBox.exe`、  
> `GAME.INST`、`GAME.GOG` 是否齐全。缺了会先警告并问一句：答 `Y` 就**只装汉化文件、不铺启动器**，  
> 并打印手动启动的三行 DOSBox 命令；不答则中止、不写盘。（脚本自己找到的目录不做这项检查。）

**启动方式**

| 版本  | 启动方式                                 |
| --- | ------------------------------------ |
| 中文版 | 游戏根目录 `简体中文.bat`                     |
| 英文版 | 照旧（Steam 开始游戏 / `DOSBOX\launch.bat`） |

中文版启动时，若已安装配音包会问一句语音（`1` 中文配音 / `2` 英文原声，15 秒不选默认中文；  
没装配音包则静默走英文原声）。  
两版共用同一批存档（`INDARK\SAVE0~4.ITD`），互不影响。

## 手动安装（不是标准 Steam / GOG 版）

光盘版、硬盘拷贝、自己拼的目录，或者游戏不在 Steam 库里（自动定位找不到）时，  
把东西**拖到脚本图标上**就行，不需要解压到游戏目录里。

| 拖什么                   | 拖给谁         | 结果                                   |
| --------------------- | ----------- | ------------------------------------ |
| 游戏目录（含 `INDARK` 的那一层） | `安装中文版.bat` | 装汉化                                  |
| `GAME.GOG` 镜像本体       | `安装配音包.bat` | 用它生成配音                               |
| `.cue`（bin + cue 那张盘） | `安装配音包.bat` | 从 cue 的 `FILE` 行读出 `.bin`，用那个 `.bin` |

判定这个目录不是标准 Steam / GOG 版时（缺 `DOSBOX\DOSBox.exe`、`GAME.INST` 等），  
脚本会把缺的东西列出来问一句：**答 `Y` 就照装** —— 汉化数据、配音数据都会放到位，  
但**不铺启动器、不写 DOSBox 配置**，因为那个环境本来跑不起来。这时要自己配 DOSBox：

```
mount  C "游戏目录"
imgmount D "游戏目录\GAME.INST" -t iso
C:   然后  CD INDARK   然后  AITD1CHS
```

装了配音包的话，`imgmount` 那行要换成 `VOICE\GAME_ZH.INST`（挂错还是英文语音）。  
补丁只负责把文件放到该在的位置。

> **镜像格式限制**：目前只有 GOG 版那份 `GAME.GOG`（353,924,256 B）能直接生成配音。  
> 光盘版的 `.bin` / `.iso` 布局与它不同，本包没有对应差分 —— 拖上去会提示  
> 「镜像大小不符」并改用游戏目录里的 `GAME.GOG`，不会白跑一遍再报错。

## 配音包（可选）

同一个 Release 里还有 **20.4 MB 的配音包**，装后中文版可用**中文语音**。它同样是差量补丁：  
用你机器上的 `GAME.GOG` 现场生成 `VOICE\ZH_TRACK01.BIN`（需要下方校验值表里那份）。  
不装则启动器静默走英文原声，不影响汉化本身。  
镜像不在游戏目录里？把 `GAME.GOG` 或 `.cue` 拖到 `安装配音.bat` 上就行（见上一节）。

## 卸载

安装时会把一份 `卸载中文版.bat` 复制到游戏根目录，**直接去游戏目录双击即可**，不必找回原来的补丁包。  
补丁包里那份同样可用，且会保留下来以后再用。

卸载只删除汉化新增的文件（包括游戏根目录里那份卸载脚本与安装记录 `chsuninstall.txt`），  
装过投掷修复的会一并删掉 `LIST_FIX.PAK`、`PRIO_FIX.ITD`；  
原版 `INDARK.EXE`、`LISTLIFE.PAK`、`PRIORITY.ITD`、`ENGLISH.PAK` 与存档**均不受影响**。

**安装记录 `chsuninstall.txt`**：安装成功后会写一份，记录游戏的绝对路径，游戏根目录与补丁包目录各一份。  
卸载时优先读它，直接定位，不必遍历硬盘；机器上有多份游戏副本（例如另开一份做汉化测试）时也不会认错地方。  
记录失效（游戏被移走或删除）时会提示，并自动改回常规查找规则；卸载成功后记录一并删除，  
避免下次安装或卸载照着旧路径误认。

## 安装脚本会做什么

给需要审计的人：

1. 定位游戏目录（读安装记录 → 拖入目录 → 向下查找 → 自身向上查找 → Steam 注册表 → 默认路径）
2. 校验原版 `INDARK\INDARK.EXE` 大小与 MD5，不符则中止
3. 询问是否安装投掷修复（回车装 / `N` 跳过），据此选择对应的一份 EXE 差量
4. 调用 `tools\xdelta3decode.exe` 生成 `AITD1CHS.EXE`（**不改动原版 EXE**）
5. 复制 `SCHINESE.PAK`、`ITD_RCHS.PAK`、`FONTCHS.FNT`、启动器与 DOSBox 配置到游戏目录
6. （仅当装了投掷修复）由原版 `LISTLIFE.PAK` / `PRIORITY.ITD` **读取生成**  
   `LIST_FIX.PAK` / `PRIO_FIX.ITD`（校验不过就不生成，绝不写坏文件；原版只读不写）
7. 写入 `chsuninstall.txt`（记录安装路径与时间）
8. **不联网、不写注册表、不修改系统设置、不触碰存档**

## 原版文件校验值

xdelta 补丁对源文件极其敏感，源不符会直接失败。装之前可以先自查：

| 文件                  | 大小            | MD5                                |
| ------------------- | ------------- | ---------------------------------- |
| `INDARK\INDARK.EXE` | 155,088 B     | `dfb8ed7a937e316815108e0c7259b6a5` |
| `GAME.GOG`          | 353,924,256 B | `9a1ec8ab71cd8a0a2106fb84007680ad` |
| `GAME.INST`         | 793 B         | `4a5b14d75ff02c2bc7ae3569d77c6b4a` |

安装结果（两者大小相同，内容差 149 字节 = 修复代码 135 字节 + 两个文件名串 14 字节）：

| 安装选项          | `INDARK\AITD1CHS.EXE` | MD5                                |
| ------------- | --------------------- | ---------------------------------- |
| 纯汉化           | 156,478 B             | `d149b5c6abbfa813f9e5975fbb479fde` |
| 汉化 + 投掷修复（默认） | 156,478 B             | `fb854ca51f658660196e1165f904ff58` |

装了投掷修复时，目录里会多出两个文件（原版那两个**仍是原来的 md5**）：

| 新增文件                  | 大小       | MD5                                |
| --------------------- | -------- | ---------------------------------- |
| `INDARK\LIST_FIX.PAK` | 75,399 B | `abdf5e18b3c2e6f5ce4aee9e240b86dd` |
| `INDARK\PRIO_FIX.ITD` | 101 B    | `0fd947a0eb45e9d9cce52b8732108c4d` |

只要 `INDARK.EXE` 的大小是 155,088 字节，一般就是这个版本。若不符，请开 Issue 说明你的来源与文件大小。

## 常见问题

**装不上，提示版本不符**  
`INDARK\INDARK.EXE` 与上表不一致。xdelta 补丁对源文件逐字节敏感，无法跨版本使用。  
请确认是 DOS 版原版，或开 Issue 附上文件大小。

**投掷修复是必装的吗？装了能退吗？**  
不是必装，回车默认装、输 `N` 跳过。想退回原版手感：重装一次、这次答 `N` 即可，  
脚本会把 `LIST_FIX.PAK` / `PRIO_FIX.ITD` 删掉（原版文件本来就没被改过）。

**投掷修复会不会改坏别的东西？**  
它只是在「背靠墙能不能扔出去」和两条音效上做修正，其余判定原样；而且**原版文件一个字节都不动** ——  
修复版是另存的新文件，卸掉汉化后英文版立刻回到完全原状。

**在 Steam 里「验证游戏文件完整性」之后汉化没了**  
这是 Steam 的正常行为，会把改动过的文件还原。重新运行一次安装程序即可。  
注意「验证」属于「比对官方文件清单、多出来的删掉、改过的还原」，所以汉化资源与投掷修复的  
`LIST_FIX.PAK` / `PRIO_FIX.ITD` 需要一并重装。反过来说，**原版 `INDARK.EXE`、`LISTLIFE.PAK`、  
`PRIORITY.ITD` 从来没被改过**，验证只会把它们判定为「无需处理」。

**杀毒软件报警**  
`tools\xdelta3decode.exe` 是 xdelta3 3.2.2 的 32 位精简解码器，本身无网络功能，  
偶有杀软对这类小体积命令行程序误报。介意的话可以从  
[xdelta 官方仓库](https://github.com/jmacd/xdelta)自行编译同版本解码器替换。

**能不能装到 GOG 版 / 光盘版 / 其他语言版**  
取决于 `INDARK.EXE` 是否是上表那份。请先备份，再对照校验值确认；不一致就不要装 ——  
补丁会在校验阶段中止，不会留下半成品文件。目录结构不必是标准 Steam 布局，脚本只认 EXE 校验值。

**中文版和英文版会互相影响吗**  
不会。中文版使用独立的 `AITD1CHS.EXE` 与独立 DOSBox 配置，原版文件保持不动，  
存档是共用的。卸载后完全回到英文版原状。

**译文和英文版语音对不上**  
翻译以英文版为底本，但少数段落参考了法语原版。  
所以个别措辞、语气不是逐字对应，这是有意的处理，不是错译。  
若你发现疑似真正的错译或漏译，欢迎开 Issue，注明书籍页或消息编号。
